# Sage QoL: Quest XP

A World of Warcraft: Forever addon that shades your XP bar with the XP you will have after you turn in the quests you have already completed. The faded orange fill runs from your current XP to current XP plus the XP reward of every quest in your log that is ready to turn in. A thin orange line marks where you will land. Hovering the bar lists each completed quest with its XP and the total.

It is part of Sage QoL, a personal set of small quality-of-life addons.

## Install

Copy this repository into `World of Warcraft/_forever_/Interface/AddOns/SageQoL_QuestXP`. The folder name must be `SageQoL_QuestXP`.

## Development

```sh
npm install
npm run check
```

`npm run check` confirms the TOC and the Lua files agree and that the Lua parses.
